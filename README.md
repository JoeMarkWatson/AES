# AES
This repository contains code for an Automatic Essay Scoring (AES) project, developed in connection with a forthcoming arXiv paper (link to be added once available).

The project includes scripts for working with both real and synthetic data. In accordance with project ethical requirements, no real data is included in this repository. However, synthetic data (and the scripts used to generate them) are provided to facilitate replication. 

Some code in this repository was co-created with large language models (e.g., ChatGPT, Gemini, DeepSeek). All code has been reviewed and run by the contributors.
